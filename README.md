# ตลิ่งคลอง · แผนที่ฉะเชิงเทรา

แผนที่เฝ้าระวังระดับน้ำในจังหวัดฉะเชิงเทรา แสดงขอบเขตอำเภอ เส้นทางน้ำจาก OpenStreetMap สถานีโทรมาตรของกรมชลประทาน และสถานีวัดระดับน้ำของเรา

หน้านี้เป็นข้อมูลเสริมสำหรับเฝ้าระวัง ไม่ใช่ระบบเตือนภัยทางการ

## เปิดดู

- ออนไลน์: เปิดลิงก์ GitHub Pages ของ repo นี้ (Settings → Pages)
- ในเครื่อง: ดับเบิลคลิก `index.html` ได้เลย

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าแผนที่ทั้งหมด (Leaflet + ขอบเขตจังหวัด/อำเภอฝังไว้ในไฟล์) |
| `stations.example.json` | ตัวอย่างรูปแบบข้อมูลสถานี คัดลอกเป็น `stations.json` แล้วใส่ค่าจริง หน้าจะอ่านทุก 30 วินาที |

## แก้ค่าที่ใช้บ่อย (ใน `index.html`)

- `THRESHOLDS` เกณฑ์ระดับน้ำ เฝ้าระวัง / เตือน / วิกฤต (ตอนนี้เป็นค่าตัวอย่าง)
- `STATIONS` ตำแหน่งและค่าของสถานี (ตอนนี้เป็นข้อมูลจำลอง `sample: true`)
- `DISTRICT_COLORS` สีประจำอำเภอ

## ข้อจำกัดที่รู้แล้ว

- ข้อมูลกรมชลประทานบน GitHub Pages จะเรียก API ตรง ซึ่งมักติด CORS จึงอาจโหลดไม่ขึ้น ต้องมีตัวกลาง (`serve.py`) ซึ่งยังไม่ได้อยู่ใน repo นี้
- เส้นทางน้ำโหลดสดจาก Overpass ต้องต่ออินเทอร์เน็ต

## ทำงานร่วมกัน

1. เจ้าของ repo เพิ่มเพื่อนที่ Settings → Collaborators
2. แก้ไฟล์แล้ว commit เข้า branch ของตัวเอง แล้วเปิด Pull Request
3. หรือแก้ตรงบนเว็บ GitHub (กดรูปดินสอที่ไฟล์) ก็ได้
