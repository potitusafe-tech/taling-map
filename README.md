# ตลิ่งคลอง · แผนที่ฉะเชิงเทรา

แผนที่เฝ้าระวังระดับน้ำในจังหวัดฉะเชิงเทรา แสดงขอบเขตอำเภอ เส้นทางน้ำจาก OpenStreetMap สถานีโทรมาตรของกรมชลประทาน และสถานีวัดระดับน้ำของเรา

หน้านี้เป็นข้อมูลเสริมสำหรับเฝ้าระวัง ไม่ใช่ระบบเตือนภัยทางการ

## เปิดดู

- ออนไลน์: เปิดลิงก์ GitHub Pages ของ repo นี้ (Settings → Pages)
- ในเครื่อง: ดับเบิลคลิก `index.html` ได้เลย

## โครงสร้างไฟล์

```
index.html              หน้าหลัก: โครงหน้า แผง และลำดับการโหลดไฟล์
css/
  style.css             ตกแต่งทั้งหมด (สีโหมดสว่าง/มืดเป็นตัวแปรอยู่บนสุด)
js/
  theme.js              จำโหมดมืด/สว่างที่เลือกไว้ (โหลดใน <head>)
  security.js           ตรวจและกรองข้อมูลสถานีก่อนใช้
  config.js             ค่าที่แก้บ่อย: เกณฑ์ระดับน้ำ ขอบเขตแผนที่ สีอำเภอ แบบตลิ่ง
  map.js                แผนที่พื้นหลัง ขอบเขต ป้ายชื่อ เมนูเลเยอร์
  stations.js           สถานี กล่องรายละเอียด ภาพตัดขวางตลิ่ง สรุปรายอำเภอ
  external.js           เส้นทางน้ำ (Overpass) และสถานีกรมชลประทาน
  main.js               ปุ่มแผง สลับโหมด และเริ่มทำงาน
data/
  stations.js           ข้อมูลสถานี (ตอนนี้เป็นข้อมูลจำลอง sample: true)
  boundaries.js         ขอบเขตจังหวัด/อำเภอ และชื่อจังหวัดข้างเคียง
stations.example.json   ตัวอย่างรูปแบบ stations.json
```

ข้อมูลเก็บเป็นไฟล์ `.js` ไม่ใช่ `.json` เพื่อให้ดับเบิลคลิก `index.html` เปิดจากเครื่องได้ (เบราว์เซอร์ไม่ยอมให้หน้าที่เปิดจากไฟล์อ่าน `.json`)

## แก้ค่าที่ใช้บ่อย

- เกณฑ์ระดับน้ำ เฝ้าระวัง / เตือน / วิกฤต: `THRESHOLDS` ใน `js/config.js` (ตอนนี้เป็นค่าตัวอย่าง)
- สถานี: `data/stations.js` หรือวาง `stations.json` (รูปแบบเดียวกัน) ข้าง `index.html` หน้าจะอ่านทุก 30 วินาที
- สีอำเภอ: `DISTRICT_COLORS` ใน `js/config.js`
- สีหน้าเว็บ: ตัวแปรบนสุดของ `css/style.css`

## ความปลอดภัย

- **Content-Security-Policy** (ใน `index.html`): รันได้เฉพาะสคริปต์ของเว็บนี้กับ Leaflet จาก cdnjs ห้ามสคริปต์ที่ฝังในหน้า และเรียกข้อมูลได้เฉพาะ Overpass กับ API กรมชลประทาน
- **Subresource Integrity**: ไฟล์ Leaflet จาก cdnjs ถูกตรวจด้วย hash ถ้าถูกแก้ระหว่างทางจะไม่โหลด
- **กรองข้อมูลสถานี** (`js/security.js`): ทั้ง `data/stations.js` และ `stations.json` ต้องผ่านการตรวจ เก็บเฉพาะ field ที่รู้จัก ตัวเลขต้องอยู่ในช่วงที่สมเหตุสมผล พิกัดต้องอยู่ในกรอบจังหวัด ข้อความถูกตัดความยาวและตัดอักขระ `< >` ไม่เกิน 500 สถานี
- **ข้อความจากภายนอก** (ชื่อคลองจาก OpenStreetMap, ข้อมูลกรมชลประทาน, ชื่อสถานี) ใส่ด้วย `textContent` เสมอ ไม่ถูกตีความเป็น HTML
- **Referrer-Policy**: ส่งแค่ชื่อเว็บไปยังเซิร์ฟเวอร์อื่น ไม่ส่ง path เต็ม

ข้อจำกัด: GitHub Pages ตั้ง HTTP header เองไม่ได้ จึงกันการถูกฝังในเว็บอื่น (`frame-ancestors` / `X-Frame-Options`) ไม่ได้ ถ้าย้ายไปเซิร์ฟเวอร์ที่ตั้ง header ได้ ควรเพิ่มส่วนนี้

## ข้อจำกัดที่รู้แล้ว

- ข้อมูลกรมชลประทานบน GitHub Pages จะเรียก API ตรง ซึ่งมักติด CORS จึงอาจโหลดไม่ขึ้น ต้องมีตัวกลาง (`serve.py`) ซึ่งยังไม่ได้อยู่ใน repo นี้
- เส้นทางน้ำโหลดสดจาก Overpass ต้องต่ออินเทอร์เน็ต

## ทำงานร่วมกัน

1. เจ้าของ repo เพิ่มเพื่อนที่ Settings → Collaborators
2. แก้ไฟล์แล้ว commit เข้า branch ของตัวเอง แล้วเปิด Pull Request
3. หรือแก้ตรงบนเว็บ GitHub (กดรูปดินสอที่ไฟล์) ก็ได้
